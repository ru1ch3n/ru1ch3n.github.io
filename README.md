# Ruichen Xu — Academic Website

Source for [ru1ch3n.github.io](https://ru1ch3n.github.io/), a fast, dependency-free academic portfolio.

## Structure

- `index.html` — research overview, selected work, and recent milestones
- `research.html` — projects and full publication record
- `teaching.html` — teaching and mentoring
- `bio.html` — biography, education, experience, talks, and service
- `news.html` — research timeline
- `assets/style.css` — shared responsive design system
- `assets/Ruichen_Xu_CV.pdf` — current curriculum vitae

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

The site uses semantic HTML and a single local stylesheet. It has no build step, analytics, trackers, or third-party font dependency.
